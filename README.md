## 🟧 How we work

- **Boundary first.** Where the data may go is decided before the first prompt is written.
- **Computed, not generated.** Figures come from systems of record; the model explains, it does not invent.
- **One pipeline, three environments.** Everything is Bicep and GitHub Actions, dev to prod by parameter file.
- **Built in the open where we can.** Tools we need ourselves become repos here.
